# Hardware

This directory contains photographs and physical hardware documentation for the SDR Experiment with WM8731 board.

Recommended organisation:

```text
hardware/
├── README.md
├── board-overview/
├── wm8731/
├── esp32-s3/
├── si5351/
└── assembly/
```

Use photographs to document connectors, modules, jumpers, wiring and significant board modifications.
